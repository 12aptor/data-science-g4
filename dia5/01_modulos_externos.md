# PIP

## ¿Qué es PIP?

pip es un gestor de paquetes de python. Permite instalar paquetes de software desde un repositorio remoto.

## Instalación de pip
En versiones de Python 3.4+, pip se instala de forma predeterminada.

```bash
pip --version
```

## Instalación de paquetes

```bash
pip install nombre_del_paquete
pip install nombre_del_paquete==1.0.4
```

## Actualización de paquetes

```bash
pip install --upgrade nombre_del_paquete
```

## Desinstalación de paquetes

```bash
pip uninstall nombre_del_paquete
```

## Listado de paquetes instalados

```bash
pip list
pip freeze
```
